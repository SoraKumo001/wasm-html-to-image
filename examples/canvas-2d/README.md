# 2D Canvas + HTML Compositing Example

Demonstrates using `createCanvas()` (HTML5 Canvas 2D compatible API backed by Skia in WebAssembly) together with `htmlToImage()` to composite HTML-rendered typography onto procedural 2D Canvas graphics.

## Run

```bash
pnpm --filter example-canvas-2d start
```

Outputs `src/output/card.png` and `src/output/card.webp`.
