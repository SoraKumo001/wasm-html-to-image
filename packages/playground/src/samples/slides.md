## 何ができるのか

- **Markdown** から PDF を作る
- 図（Mermaid）と数式（KaTeX）をそのまま書ける
- 文字は選択でき、ベクターのまま出力される


## 変換の流れ

```mermaid
flowchart LR
  A[Markdown] --> B[HTML]
  B --> C[ページ割り付け]
  C --> D[PDF]
```


## 性能の目安

| 項目 | 結果 |
|---|---:|
| 10 ページの文書 | 約 0.8 秒 |
| 図 5 点を含む文書 | 約 1.2 秒 |
| 出力サイズ | 約 400 KB |
