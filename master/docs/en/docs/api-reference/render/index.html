render() & Options Reference

render() is the primary function for converting HTML or raw images into the target format.

Signatures​

// wasm-html-to-image/single
export function render(
  options: HtmlToImageOptions,
): Promise<Uint8Array | string>;

// wasm-html-to-image
export function htmlToImage(
  module: HtmlToImageModule,
  options: HtmlToImageOptions,
): Promise<Uint8Array | string>;

:::note Return Type Returns a string for svg format, and Uint8Array for all other formats (png, jpeg, webp, apng, gif, tiff, avif, jxl, pdf, raw, thumbhash). :::

Options (HtmlToImageOptions)​

Core Options​

OptionTypeDefaultDescription
valuestring | string[] | Uint8Array | ArrayBuffer-Input data (HTML string, HTML array for multi-page PDF, or image buffer)
urlstring-URL to fetch and render when value is omitted
baseUrlstring-Base URL for resolving relative assets
widthnumberRequiredViewport width (HTML) or target output width (image)
heightnumberautoViewport height (HTML) or target output height (image)
formatOutputFormat"png"Target output format (png, jpeg, webp, apng, gif, tiff, avif, jxl, raw, thumbhash, svg, pdf)
scalenumber1Pixel density of raster output from HTML input (0-16). width stays in CSS px and the page is drawn scale times larger (scale: 3.125 turns an 800px layout into a 2500px image, with text and shapes re-rasterized rather than stretched). Ignored for svg / pdf and for image input.
dpinumber96 × scaleResolution written to tiff, in pixels per inch. A print shop reads the physical size from it.
colorSpace"srgb" | "cmyk""srgb"Output color space of tiff and pdf. "cmyk" is for print: TIFF becomes a separated CMYK image with transparency flattened onto white, and PDF has every fill, stroke and image rewritten to DeviceCMYK. The conversion is the plain device formula (K = 1 − max(R,G,B), black stays K only) with no ICC profile, so saturated screen colors are not gamut-mapped. Ignored for other formats.

Rendering untrusted HTML (limits)​

When rendering user-supplied HTML, always restrict where it may fetch from and how much. By default any host is fetched, and on Node local files under baseUrl are read.

limits keyTypeDescription
timeoutMsnumberTimeout for the whole render. Each individual fetch is aborted by the remaining time
maxResourceCountnumberMaximum number of resources to load
maxResourceBytesnumberMaximum bytes for a single resource
maxTotalResourceBytesnumberMaximum total bytes for all resources
allowedProtocolsstring[]Allowed URL protocols (e.g. ["https:"])
allowedHostsstring[]Allowed hostnames
blockedHostsstring[]Blocked hostnames
confineFilesToBaseUrlbooleanOpt-in (Node only). Restrict local file reads to files inside baseUrl (symlinks resolved). ../ escapes are refused, and with no baseUrl no local file is read at all
await render({
  value: untrustedHtml,
  width: 1200,
  baseUrl: "/srv/assets",
  limits: {
    timeoutMs: 10_000,
    maxResourceCount: 20,
    maxTotalResourceBytes: 10_000_000,
    allowedProtocols: ["https:"],
    confineFilesToBaseUrl: true,
  },
});

Fetched resources are cached in-process (up to 256 entries / 64 MiB, least-recently-used eviction, remote entries keyed per User-Agent). Call clearResourceCache() if the source files changed.
