API リファレンス

wasm-html-to-image の API 一覧とオプション詳細です。

📄️API 概要

wasm-html-to-image は、初心者向けのゼロコンフィグ関数から、高スループットサーバー向けの詳細制御、ワーカー並列化まで、目的に応じた柔軟なインターフェースを提供します。

📄️render() & オプション

render() は、HTML または画像を目的のフォーマットへ変換・描画する統一関数です。

📄️ランタイム別ガイド

各プラットフォーム・実行環境ごとのセットアップと最適な利用方法を解説します。

📄️フォント & リソース解決

HTML 描画では、外部画像やフォントファイルの読み込みが不可欠です。wasm-html-to-image は柔軟なリソース解決と強力なキャッシュ機構を備えています。

📄️並列処理 (Workers)

wasm-html-to-image/workers は、Node.js の worker_threads やブラウザの Web Worker を利用した並列ワーカープールを提供します。

📄️CLI ツール

wasm-html-to-image は、ターミナルから直接 HTML や画像を高速に変換できるコマンドラインインターフェース（CLI）を提供します。

📄️ログ & 診断 (Diagnostics)

レンダリングパイプラインの詳細な追跡、パフォーマンス測定、リソース取得エラーのデバッグを行うための機能です。
