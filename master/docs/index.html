wasm-html-to-image

High-Performance HTML to Image & Image Optimization Engine

ドキュメントを読む 🚀Playground デモを試す
⚡

単一 WASM モジュール統合

Satoru（HTMLレイアウト・描画）と wasm-image-optimization（画像変換・最適化）を1つの Emscripten モジュールに統合。メモリとプロセスのオーバーヘッドを最小化します。

🎨

多彩な入出力フォーマット

HTML 文字列・URL に加え、画像バイナリを直接入力可能。出力は SVG、PNG、JPEG、WebP、AVIF、RAW、ThumbHash、さらに複数ページ対応 PDF まで幅広くカバーします。

🚀

ゼロコンフィグの Single 版

wasm-html-to-image/single をインポートするだけで、WASM ファイルの配備や初期化コードなしに即座に render() を実行可能。Node.js やバンドラ環境で極めて容易に使えます。

🌐

Cloudflare & Edge 対応

wasm-html-to-image/workerd および edge-light サブパスを提供。ヘッドレスブラウザが動作しないエッジワーカー環境でも高速・低メモリで OGP 画像生成が可能です。

🧵

並列 Worker プール

wasm-html-to-image/workers により、Node.js の worker_threads や Web Worker を用いたマルチスレッド並列処理を標準サポート。大量バッチ生成でもイベントループをブロックしません。

⚛️

React / Preact / Tailwind 連携

React / Preact コンポーネントの直接描画（JSX support）や、UnoCSS ベースの Tailwind ユーティリティクラスによるインラインスタイリングをシームレスに実現します。
